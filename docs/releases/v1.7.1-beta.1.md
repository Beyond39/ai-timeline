## 安装与校验

下载 **ai-conversation-visual-navigator-v1.7.1.zip** 和 SHA256SUMS.txt；GitHub 自动生成的 Source code 压缩包不是安装包。

```powershell
Get-FileHash .\ai-conversation-visual-navigator-v1.7.1.zip -Algorithm SHA256
Get-Content .\SHA256SUMS.txt
```

解压到固定目录，确认根层 manifest.json；在 chrome://extensions 打开开发者模式并加载该目录。现有用户先分别导出资料库与知识备份，保留原扩展条目、路径和 Profile，更新后重新加载。详细说明见仓库 docs/installation.md 及包内 docs/PUBLIC_BETA.md。
