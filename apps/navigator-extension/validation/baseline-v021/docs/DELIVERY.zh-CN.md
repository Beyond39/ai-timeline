## 规则与模型各自完成程度

**规则整理可直接使用。** 依据连续问答、问题与回答中的关键词及内容变化给出初步建议。内置主题偏向插件开发，普通规则组最多 8 轮；无法识别共享关键词时保留单轮，人工或已确认段默认保持。规则结果明确标记，不保证语义分段质量。

**外部模型整理的导出、导入、预览和确认闭环已完成。** 整理包包含完整可取得正文、稳定 QA / 消息 / 版本引用、人工段、邻接批次上下文、中文提示词和返回格式。可返回整个范围的 `groups`，或汇总全部 `batches` 后一次导入；缺少批次不会应用。批次对齐人工边界，较长人工段允许超过目标轮数并提示。

当前模型适配器接收外部 JSON，没有自动模型调用、API Key 配置或联网分析。`method.kind=model` 记录输入的外部模型声明，不能认证其真实出处；内容质量和理由需人工核对。将整理包给外部 ChatGPT 或其他模型由用户自行操作。

## 限制与待确认

- 工具仅连接内置浏览器，未连接真实 Chrome 或 Edge；未实际安装本扩展、运行真实 Manifest 服务工作线程、验证 Side Panel / activeTab / scripting 权限或采集登录后的 ChatGPT 页面。Chrome 与 Edge 的这些适配、下载及剪贴板仍需实际确认。
- 页面采集仅含已加载且能够可靠识别的 DOM。未加载历史、未展示分支、附件正文及缺失时间保持未知。页面变化可能影响独立 ChatGPT 适配器；内置页面验证不证明当前 ChatGPT 选择器已适配。
- 未实现自动模型调用、自动采用、Tree / Story、因果图、云同步或多平台采集。外部模型理由和语义质量未实测。
- repository 读取完整本地状态，整理包保存正文副本。超长对话、大量建议与超大导出的内存、容量、模型上下文和响应速度未压力验收。
- 签名采取保守的过期判断；源或地图更新后需要重新生成。备份恢复重建本地 ID，保留旧建议和证据，但待采用建议与整理包必须重新生成。
- 后续成员或人工设置变化使撤销不再安全时会拒绝覆盖并说明原因。撤销分段后新建的主题字典保留，便于持续复用颜色。
- Chrome、Edge 和不同配置的数据不共享；旧 V0.1 不能直接读取升级后的 V2 数据库，回退见升级说明。
