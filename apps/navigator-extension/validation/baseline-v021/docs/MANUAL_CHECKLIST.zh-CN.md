# V0.2 真实浏览器体验清单

本轮开发已进行域功能检查，并开展隔离浏览器验证；执行结果以交付报告为准。下面的真实 Chrome / Edge 安装与 ChatGPT 登录页体验仍由你最终确认。先用两条熟悉的真实对话；备份恢复到独立新项目，避免与原项目混淆。

| 操作 | 核对结果 |
| --- | --- |
| V0.1 原插件导出备份 → 原扩展条目刷新 V0.2 → 打开旧项目 | 加载目录与扩展身份不变；旧消息、正文版本、路径、Q/A、人工标题 / 主题 / 边界可继续读取，无项目被重置 |
| 真实 ChatGPT 页点击插件图标 → 采集 → 预览 → 项目保存 | 标题、地址、角色、正文、消息数对应已加载页面；历史、分支、来源时间和附件取得范围明确标记 |
| 展开长回答、工具信息，再查看未回答问题 | 全文可读到末尾，工具 / 附件可折叠；末尾用户问题有独立轮次与未回答状态；点击原文能定位真实消息 |
| 整理当前对话 → 选择路径与范围 → 生成本地规则建议 | 清楚标记规则结果；显示原 / 建议节点数量、连续成员、理由、主题和原文引用；预览尚未改变地图，内部端点扩展范围有提示 |
| 修改建议标题 / 主题 → 移动相邻边界 → 合并 / 按 Q/A 拆分 → 保存预览 | 分组仍完整有序覆盖范围，无重复、遗漏或跨分支；保存后重开建议，编辑继续存在；原文按钮定位真实 Q/A / 消息 |
| 确认采用建议 → 点击新彩色节点 → 切换成员 Q/A | 地图显示标题、成员数、主题和已确认状态；全部 Q/A 与长正文保留；选择 Q/A 时地图定位所属新节点，同主题颜色一致 |
| 生成建议后拒绝或关闭 → 重开已保存建议；另一次确认后撤销 | 拒绝 / 关闭不改变原图；拒绝状态可查；“撤销最近修改”恢复整次整理前分组，无原文丢失 |
| 先人工改名、设主题或分段，再生成并修改新建议 | 原人工设置默认受保护；改变这些设置时出现明确冲突，保存重验后必须复核勾选；继续编辑清除旧勾选，未确认不覆盖 |
| 生成待确认建议 → 在 ChatGPT 追加消息并重复保存，或更改现有地图 | 原逻辑对话、旧消息和版本保留；旧建议显示需要复核 / 过期，不能静默采用；重新生成建议可整理最新真实成员 |
| 导出整理包 → 复制提示词 / 分批提示词 → 外部模型返回 JSON → 导入 | 稳定 QA / 消息 / 版本引用和邻接上下文保留；每批只覆盖核心成员；全量 groups 或全部 batches 汇总可预览；明确标记外部模型语义结果，无自动 API 调用 |
| 在模型结果副本中改成不存在的 QA、消息或版本 ID；少一轮或只导入一批 | 出现具体引用 / 覆盖 / 批次错误，现有地图和全文保持可读；使用原有效结果仍可进入预览 |
| 管理主题 → 预览重命名 / 合并影响 → 取消，再确认 | 影响片段、对话与建议数量清楚；取消不改标签；重命名保留颜色，合并使用目标颜色；待确认建议需重新复核 |
| 第二条对话加入同一项目 → 搜索回答后半段 → 重开插件 | 搜索进入真实对话、Q/A、原文消息；有继续加载入口；项目、建议、确认分组、人工修改和颜色持久保留 |
| 导入 V0.1 备份；V0.2 确认整理后导出 → 重新导入备份 | 两版备份可读；原文、来源、版本、成员、主题和人工修改保留；恢复后的旧待确认建议 / 整理包需重新生成，已确认地图完整可读 |
| 导入含分支 conversations.json，在 Chrome 与 Edge 分别加载 | 当前路径按可靠节点恢复，其他分支独立；核对侧栏开启、activeTab 授权、真实采集、IndexedDB 重开及备份下载 |

反馈请写“浏览器及版本、操作步骤、预览 / 错误提示、实际结果、期望结果”。涉及分段请补 Q/A 序号；涉及重复保存请注明是否取得源消息 ID；涉及模型导入可提供脱敏的整理包 ID、批次 ID 和失败引用。无需提供账号密码或 API Key。
