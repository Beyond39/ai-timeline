# V0.2 中文安装、升级与操作说明

## 加载插件

Chrome：打开 `chrome://extensions` → 打开“开发者模式” → “加载已解压的扩展程序” → 选择：

```text
D:\mytools\GPT-SaaS\apps\navigator-extension\dist\ai-conversation-visual-navigator
```

这个文件夹的第一层必须能看到 `manifest.json`。ZIP 需先解压，不是 CRX 安装包。固定工具栏插件图标后，在 ChatGPT 对话页面点击它。浏览器扩展管理页的“扩展程序选项”也可打开完整项目页。

本版 ZIP：`D:\mytools\GPT-SaaS\apps\navigator-extension\dist\ai-conversation-visual-navigator-v0.2.1.zip`。V0.2.0 升级到 V0.2.1 沿用原数据库与加载目录；先备份，关闭插件页，刷新原扩展条目后重新打开。不要卸载重装。

Chrome 以 116+ 的 Side Panel API 为目标。Edge 桌面版可在 `edge://extensions` 加载同一份文件夹；Microsoft 官方列出 MV3 的 `sidePanel` 和 `scripting` 支持，但本包未在实际 Edge 中安装验收，仍需确认当前浏览器的侧栏开启、临时页面授权和下载行为。[Chrome Side Panel 官方文档](https://developer.chrome.com/docs/extensions/reference/api/sidePanel)，[Edge API 支持表](https://learn.microsoft.com/en-us/microsoft-edge/extensions/developer-guide/api-support)。

点击图标时直接请求打开侧栏；如果当前浏览器没有可用的 `sidePanel.open` 或打开失败，代码提供带来源标签页 ID 的完整项目页降级入口。旧版浏览器的 Manifest 兼容性本身仍需实际确认，降级入口不能替代缺失的扩展 API。

## 从 V0.1 原地升级

1. 先在原插件导出重要项目备份，记下扩展管理页显示的加载目录。
2. 本次源码和标准 `dist/ai-conversation-visual-navigator` 安装目录已更新为 V0.2；在浏览器扩展管理页点击**原有扩展的刷新按钮**，再重新打开插件页面。
3. 继续使用相同浏览器配置、相同扩展条目和相同加载目录。若原来加载的是源码根目录，就刷新该目录；不要切换到另一份 ZIP 解压目录。
4. 打开已有项目，核对原文、Q/A、人工标题、主题和边界。数据库沿用原名称并增量迁移，不重置旧项目。V0.1 备份可继续通过“导入 JSON / 备份”恢复。

无需卸载扩展。卸载重装或改变开发版扩展身份可能使浏览器使用另一份本地数据库。完整迁移字段见 `DATA_CONTRACT.zh-CN.md`。

## 第一次真实采集

1. 打开一条 ChatGPT 对话，等待页面显示消息。若需要更早历史，先自行滚动，让网页加载它。
2. **在这条 ChatGPT 页点击工具栏插件图标**，取得 `activeTab` 的当前页临时授权。
3. 在侧栏点击“采集 / 更新当前对话”。插件观察约 650 毫秒，对比文本变化与可见停止生成按钮。
4. 预览会显示标题、来源地址、源对话 ID、消息数、用户问题数、角色、路径、采集时间和不足之处。打开“检查实际取得的消息正文”可分批核对全文。
5. 选择已有本地项目，或选择“＋ 创建新的本地项目”并填名称。ChatGPT 原生项目无法确认时，可在独立字段手动记录名称。
6. 点击“保存到本地项目”。保存后可在侧栏逐轮阅读；“项目地图 ↗”打开完整项目页。

预览可“稍后处理”或“丢弃”；未完成的导入预览保存在 IndexedDB，重新打开或点击刷新可以继续处理。再次采集会替换尚未提交的旧页面采集预览。

**范围说明**：仅读取当前网页已加载、展示且能够可靠识别的内容。没有读取整个账号、所有项目或全部分支的接口。消息时间缺失显示未知；“采集于”只表示保存时刻。短观察期间稳定不表示回答已生成结束。

## 保存更新与项目归属

在同一对话继续聊天，点击“采集 / 更新”并检查预览。按源对话 ID 更新已有逻辑对话。消息按可靠源 ID 优先映射；正文变化创建版本，旧版本在“来源、身份与版本”中可展开。本次没看到的历史不会被删除。

没有源 ID 时，只有可确认的有序上下文才进行回退匹配，预览后的保存结果和采集快照显示“不确定匹配”数量。歧义或断开的范围会另存记录 / 阅读路径，可能出现保守的重复记录。仅有相同文本不进行全局合并。无源 ID 且 URL 只是 ChatGPT 首页时，不用首页地址把不同新聊天合成同一对话。

本地项目和来源平台原生项目各自记录。通过阅读器的“调整本地项目归属”可将对话、消息、Q/A、分段及人工修订移动到其他已创建项目。保存预览中把已存在对话选择到其他项目，也会移动该记录；预览会说明这一影响。

## 地图与完整问答

- 每轮用户问题初始对应一个 Segment。节点显示标题、所属对话、真实 Q/A 数量、时间状态和主题。
- 点击节点查看实际成员；点击阅读器的轮次索引、上一轮、下一轮或跳转，地图同步选择对应节点。
- 节点详情的“完整路径的全部 Q/A”可退出当前 Segment 的成员范围，浏览整条已存路径。
- “展开完整长回答”展示全部已保存正文；“展开本轮全部回答 / 工具信息”一次展开本轮。工具、非文本引用和正文版本可分别折叠。
- “所在完整对话 / 本地原文”显示路径中的所有角色。“定位到本地完整对话原文”会打开包含目标消息的分页并高亮。
- 原文每批 35 条，Q/A 索引每批 25 轮，地图每批 60 节点，搜索每批 35 结果，均有继续浏览入口，批次不是数据上限。
- “打开保存的来源 ↗”仅打开真实保存的地址；没有地址时按钮不可用。导出文件只有 ID 而没有地址时不会拼造链接。

从左侧选择对话和已存路径，或勾选“地图包含其他已存路径”。分支之间不会拼成一条线性回答。导出缺少 `current_node` 时显示当前路径未知；你可在预览中明确选择，也可以只保存关系后再浏览。完整对话的“全部已存消息”用于检查各分支所有消息，其列表不声称是单一发生顺序。

## 人工整理与颜色

在节点阅读器中重命名、输入逗号分隔的主题、合并下一相邻段或选择一轮之后拆分。主题的第一个标签决定节点主色，其余标签仍显示名称；同一项目同一主题使用持久颜色和图例。跨对话主题共享标签，跨对话 Segment 不允许合并。

合并前会显示两段的标题、数量和合并结果；拆分在真正的 Q/A 边界进行。操作产生人工修订，支持“撤销最近修改”。标题、主题和外侧人工边界在再次采集时保留。新补采轮次落在原人工边界内部时加入该连续段并标记“请复核”；不会隐藏新内容。若新增成员使旧撤销操作不再安全，显示原因，允许在当前成员上重新整理。

## 整理建议 → 预览 → 确认

1. 在项目中选择一条已保存对话，点击“整理当前对话”。选择可靠取得的**阅读路径**、起始轮次和结束轮次。分支需分别整理。端点落在现有片段内部时，范围会扩展到完整片段边界，预览明确提示。
2. 点击“生成本地规则建议”。规则使用连续轮次、词语与内容变化做初步分组，明确显示“本地规则结果”；已有人工或已确认分段优先受保护。建议独立保存，地图此时保持原样。
3. 对照“原有分组”和“建议分组”、节点数量及成员 Q/A。修改标题和逗号分隔主题；通过“将本段末轮移到下一段”“将下一段首轮移入本段”、相邻合并或按指定 Q/A 边界拆分调整分组。不能重排成员或跨分支合并。
4. 点击成员或“支撑建议的原文引用”可收起窗口，打开真实 Q/A / 原文消息；预览编辑先保存为建议。再次进入整理窗口，从“已保存的整理建议”继续处理。
5. 点击“保存修改后的预览”重新校验。若改变原人工标题、主题或边界，下方列出冲突；对照后勾选“我已对照原分组……”复核。再次编辑会清除这次勾选。出现新冲突时先停留在预览，不能直接覆盖地图。
6. 点击“确认采用并更新地图”。地图显示新标题、主题颜色和真实成员数；点击节点展开全部成员，选择 Q/A 时地图同步定位。采用结果记录为一整次人工修改。
7. “拒绝建议”只改变建议状态；关闭窗口不会采用。确认后在完整项目页点击“撤销最近修改”（侧栏为“撤销”）恢复整次整理前的分段；如果后续采集已改变成员、撤销不再安全，显示原因。

“全部整理状态”可筛选未整理、待确认、已确认和需要复核。待确认表示存在建议，不表示地图已经被改动。源正文、生成状态或现有导航发生变化时，旧待确认建议显示需要复核并禁用采用，应基于最新数据重新生成。完整正文始终由原 Q/A / Message 关系读取，整理标题与理由不是原文替代品。

## 导出给 ChatGPT 的分析包与导入模型 JSON

在整理窗口选择路径和范围，点击“导出给模型的整理包”，设置每批目标轮数，再点击“生成并下载整理包”。可以下载整个 JSON、复制完整提示词、下载提示词，或展开各批次复制提示词 / 下载这批 JSON。

把提示词及对应 JSON 提供给外部 ChatGPT 或其他模型。包中带稳定 QA、消息、正文版本引用，长对话每批附相邻上下文；模型只将本批核心 Q/A 列为成员，上下文不能重复计入。返回格式与要求已写入提示词：

- 全量结果使用 `format: "acvn-organization-result"`，提供 `analysisPackId`、所属对话 / 路径、`sourceVersion`、方法 / 版本及完整有序 `groups`。
- 分批处理需把所有结果汇总为同一结果 JSON 的 `batches`，每项使用对应 `batchId` 和本批 `groups`。必须包含原整理包的全部批次；单独一批不可应用。
- 每个建议组包含标题、主题、连续 QA ID、理由与支撑每轮的原文消息 / 版本引用；格式样例以导出提示词为准，不手工猜测引用。

展开“导入外部模型分析 JSON”，粘贴结果或“选择 JSON 文件”，再“校验并预览 JSON”。解析、引用、成员覆盖或批次校验失败时，地图继续保留。通过后明确显示“外部模型语义结果”，仍需修改、复核并人工确认。模型声明来自导入结果，插件未验证外部模型实际如何运行。

**V0.2 不自动调用模型 API，不需要 API Key，也不会由此上传对话。**导出的完整正文由你自行交给所选外部模型。模型适配接口已独立，后续可扩展自动调用。

## 项目主题管理

点击“管理主题”，选择现有主题和重命名 / 合并操作。重命名保留原主题颜色；合并使用目标主题颜色并维护别名。确认前会显示影响的有效片段、对话及整理建议数量；取消预览不改动标签。待确认建议需要重新复核，避免采用旧主题名。同主题只表示标签归类，不代表因果或思想关系。

## 搜索

完整页面或侧栏输入项目内的标题、问题或回答原文。结果显示真实对话标题与角色。点击命中进入对应 Q/A 并高亮消息，或者进入没有 Q/A 归属的系统 / 辅助原文。搜索覆盖完整当前正文，节点短标题不是搜索数据来源。

## 历史导入

点击“导入 JSON / 备份”，选择 ChatGPT `conversations.json`、单个含 `mapping` 的 ChatGPT 导出对象，或旧工程的通用 JSON（包含 `provider`、`project_title` 和 `conversations`）。预览中可以取消勾选不需要的对话，并统一选择归属项目。

ChatGPT 导出保留 mapping 的父子图、无正文的节点和原始消息 JSON，再由当前节点向父链恢复阅读路径。其他叶分支、断链或未连通消息另行表达。不会按时间把所有分支直接平铺成“当前对话”。通用格式有父节点时也保留关系；没有父节点时按文件给定消息顺序阅读，不猜父子关系。

每条对话单独提交，局部失败不覆盖已完成内容，预览保留用于重试。一次性读取整份文件到内存，建议第一轮先使用少量真实对话；超大导出的内存与性能尚未验收。

## 备份、恢复与删除

“导出备份”下载项目 JSON，包含原文、来源图、快照、正文版本链、阅读路径、问答、Segment 成员、主题、整理建议、整理包和人工修订。“导入 JSON / 备份”可恢复 V0.1 或 V0.2 备份；推荐选择“恢复为独立的新项目”，避免混淆核对。追加到现有项目会新增一份恢复记录，不替换既有同源对话。

恢复时重新分配本地 ID 并重建引用，来源平台 ID 保持原样。恢复后的地图和全文仍使用统一对象关系。附件备份保留已取得的引用与元信息，不包含从未下载的文件正文。

恢复后的旧待确认建议和整理包标记需重新生成 / 导出，不能直接采用改变本地 ID 之前的分析结果；已确认的分段、人工标题、标签、成员和正文仍可阅读。

“删除项目”要求输入项目名，随后删除该项目已保存的对话、原文、版本、路径、Q/A、地图和修订。尚未保存的独立预览可通过“丢弃此预览”清理。

数据属于当前浏览器用户配置下的扩展 IndexedDB；Chrome 与 Edge 不共享数据。卸载扩展、清除相关浏览器数据或改变开发版扩展身份可能丢失本地记录。使用同一加载目录进行更新，并在迁移 / 卸载前导出备份。

## 遇到问题

无法识别页面：确认地址为 `chatgpt.com` 或 `chat.openai.com`，对话已显示角色消息；等待加载后重试。若页面标记已改版，使用 JSON 导入，并记录预览给出的具体原因以便维护适配器。

当前页未授权 / 标签已关闭：回到目标 ChatGPT 标签页，再点击工具栏插件图标。在完整项目页采集时使用最近由图标记录的来源标签；重新授权后重新打开完整页面。首次直接打开“扩展程序选项”没有网页授权时，文件导入和本地阅读仍可使用。

未回答：表示已存阅读路径中未取得助手回答；部分采集不能证明源平台确实没有回答。可在页面显示回答后主动更新。

地图少了其他分支：选择对应阅读路径或勾选其他路径；页面未展示的分支需要通过实际导出文件补入。

人工冲突：刷新读取最新版本后重新操作，事务会拒绝覆盖其他窗口已变更的节点。失败信息显示在顶部，已成功保存的对话继续可读。

整理结果导入失败：使用同一插件刚导出的整理包，核对返回 `analysisPackId`、路径、源版本和 QA / 消息 / 版本 ID；长对话需汇总全部批次。重新采集或修改地图后，请重新导出分析包。

本轮已获用户允许执行功能检查。域逻辑与隔离浏览器验证的实际结果见交付说明及 `dist` 内验证报告；隔离浏览器使用明确标记的验证数据与本地 IndexedDB / 后台桥接。真实浏览器扩展安装、Chrome / Edge 侧栏与授权，以及登录 ChatGPT 页的 DOM、流式状态、来源 ID 和附件适配仍需实际确认。固定验证数据不代表已采集你的真实对话。
