## 实际完成

**采集诊断与覆盖**：复查并增量修改独立 ChatGPT 适配器和后台。`chatgpt-dom-v3` 统一 detect / collect / normalize，区分不支持、未加载、结构识别失败、来源关闭、授权不足、正文不可得、生成变化、附件引用和部分范围。预览显示实际计数、角色、可靠源 ID 和能力，未知历史 / 分支 / 时间 / 原生项目不推测。诊断默认严格白名单，可附加来源先展示再主动勾选。补采保留旧消息，同文不同源 ID 独立，完整 Q/A 包含未答、多助手及工具。

**完整正文阅读**：新增本地安全 Markdown 子集、取得完整覆盖的 DOM 结构表示、代码 / 表格横滚、全文与代码复制、懒生成原文入口。长回答和工具首次展开才排版，正文永不截断；渲染与不可变原始正文 / 版本分开。导入渲染提示不冒充真实页面还原。历史引用直接读取并展开确切版本，其余版本按消息经主动按钮加载。Unicode 搜索仍高亮保存原文。HTML 不执行，图片不自动请求，公式保留表达式。

**范围查询**：IndexedDB V3 增量索引，快照摘要派生缓存与快照写入同事务同步，兼容 V1 / V2 数据与 Schema 1 / 2 备份。项目导航不返回全文、建议组或历史证据副本；单轮只读目标消息与当前版本，按 qaIds 索引找所属段；对话默认 35 条一批；项目搜索游标扫描仅保留当前命中页；建议详情只读目标建议及所属对话；备份只读目标项目。修复范围重开预览遗漏源消息身份提升依据，保持两可靠 ID 与唯一候选保护。

**原功能和数据保护**：规则 / 外部 JSON 整理包、编辑预览、确认 / 拒绝、人工冲突复核、主题管理、连续段拆合、整次撤销、地图 / Reader / 搜索联动、导入及备份继续连接实际数据。历史证据与复核状态没有因改标题、主题、拆合被替换；补采改变回答归属后历史证据仍可备份恢复。过期校验跨请求重算，指纹算法形状保持 V0.2.1，读取投影本身不会使旧建议过期。

基础三项按本轮优先级完成。层级地图、Tree / Story、思想关系和建议归档明确放下一版，已有 Snake 地图继续真实可用。Python 工程保留，未新增外部模型调用、联网、付费服务或扩展权限。

## 性能证据和实际限制

固定样例为 3 项目、500 / 2,000 / 无关 1,000 轮、7,000 消息、24 建议、2 整理包，状态约 127.56 MB。预热后 5 次配对计时，字节计量另跑；环境、每次值、范围和数据量完整记录。详见 `PERFORMANCE_V0.3.zh-CN.md`。

2,000 轮中位耗时：地图 1,056.3→968.4 ms；单轮 495.9→5.1 ms；搜索第二页 1,567.2→989.9 ms；建议详情 560.3→551.3 ms。单轮实际只取 8 行（含 2 条消息、2 当前版本），不读快照 / 整理包，保留约 88 KB。所有新范围请求断言只取得所选项目，旧版每次取得全部 3 项目、约 127.54 MB。

地图有待确认建议时仍取得相关路径 Message / Version 的完整行后投影，2,000 轮地图实际约 70.94 MB，保留约 9.72 MB；没有声称这部分实现无正文成本。搜索为准确 total 每页重扫本项目；写入仍整库原子读取并保护全局 revision。超大导入、容量、真实扩展启动及布局未压力验收。

## 未验证与下一轮

- 当前浏览器控制只提供内置 Chromium，没有真实 Chrome / Edge 或已登录 ChatGPT 的控制入口。未实际安装 MV3、执行真实服务工作线程、确认 Side Panel / activeTab / scripting、登录后当前 DOM、真实生成更新、附件、系统剪贴板或下载。合成 DOM 和桥接不能替代这些验收。
- 附件保留引用，文件正文不下载；未加载历史、未展示分支和未知时间保持未知。适配器基于 V0.2.1 已有选择器及代码失败维护样例，没有编造当前线上结构。
- Markdown 是保守子集；完整 CommonMark 嵌套列表 / 脚注、语法着色和公式排版未完成。格式不足时完整原文始终可读。
- 模型整理是用户外部 JSON 的声明与引用校验流程，不能认证真实模型出处，语义质量未实测；没有自动调用或自动采用。
- 层级地图、建议归档、Tree / Story、关系图、云同步和多平台采集未实现。

下一轮详细提示词在 `NEXT_V0.4_PROMPT.zh-CN.md`。优先真实安装与采集验收、减少源指纹与写入范围，再做稳定 ID 的项目→对话→片段→Q/A 层级浏览。
