# V0.3 范围读取与实际性能

测量记录：`dist/V03_PERFORMANCE_REPORT.json`；查询回归：`dist/V03_STORAGE_BROWSER_REPORT.json`。2026-10-04（上海时区）在 Windows 上的内置 Chromium 154、真实 IndexedDB 中运行，UA / 32 逻辑线程 / 浏览器报告 32 GiB deviceMemory 保存在 JSON；不是 Chrome / Edge 扩展安装性能。

## 样例与方法

明确标记的合成固定样例：3 项目，分别 500、2,000 和无关 1,000 轮，共 7,000 消息、24 建议、2 整理包，JSON 状态 127,558,026 字节。没有读取用户账号或扩展数据。

使用单独的 `acvn-validation-v03-performance-final` 测试库，验证包装仅把规范库名映射到此名字；两版读取同一组稳定 ID 和实际数据。V0.2.1 基线保存在 `validation/baseline-v021`，只将 `indexedDB.open` 版本 2 改为 3，使其能打开同一个已迁移测试库，读取算法未改。测试库清理有实际库名检查，不依赖端口隔离假设。

每项两版各预热一次，再交替执行先后顺序进行 **5 次配对测量**。耗时包含 repository、IDB 与签名计算，排除布局、网络、MV3 权限、冷启动和样例装载。计时期间关闭逐字节监测；另执行一次详细计量，记录实际返回到 JS 的完整数据行字节与投影保留字节。JSON 有每次值、最小 / 中位 / 最大 / 平均数和逐 store / query 范围。

## 实际读取与保留量

旧版每项都读取整库：127,536,782 字节，包含全部 3 个项目。下表为新版本，MB 用十进制。所有测量均断言 `fullStateReads=0`、实际取得行的 projectId 只来自所选项目。

| 规模 | 操作 | 实际取得 MB | 投影保留 MB | 实际取得记录数 |
| --- | --- | ---: | ---: | ---: |
| 500 | 地图 | 17.727 | 2.437 | 3,021 |
| 500 | 单轮 | 0.174 | 0.088 | 8 |
| 500 | 搜索页 | 3.901 | 0.364 | 1,501 |
| 500 | 建议详情 | 10.114 | 2.065 | 3,010 |

单轮的 8 行包括 QA、对话、路径头、有效 Segment、2 条消息及 2 个当前版本；不读取 snapshots 或 analysisPacks。路径行仍由 IDB 实际取得后只保留头，因此随着长路径其载入字节会增加，报告没有把这部分算作零成本。

地图存在待确认建议时，要取得相关路径的当前 Message / Version 完整行再投影，保证写后过期校验；因此大项目地图和建议详情改善有限，不能声称全插件获得百倍加速。搜索逐条丢弃正文，只保留当前结果页；保留字节不包含最后结果摘要，且每页仍重扫本项目以保持准确 total。

## 调用路径盘点及边界

旧版 `projects / view / qa / conversation / search / latestDraft / backup / organizationContext / organizationSuggestion / topicPreview` 共用整库 `readState()`；常见打开项目再选一轮涉及至少 3 次整库读取。

现在业务 `readState()` 留在写入队列 `mutate`，其他入口使用范围查询：项目导航不返回全文、建议组正文和历史证据；单轮只读目标消息，其他历史另按消息读取；对话每批最多 80 条，默认 35；搜索每页有限结果；备份只读指定项目的完整关系；建议详情仅目标建议与所属对话当前源投影；最新预览先描述符选取再取最新完整载荷。

`snapshotSummaries` 为派生缓存，V1 / V2→V3 迁移建立，写入与原始快照同事务同步，不进备份。正文仍同时存在于 Message、不可变 Version 和原始导入 / 快照 / 整理包中，未压缩或删除这些追溯副本。

9 项实际 IDB 回归覆盖范围隔离、完整长正文、分页无遗漏、Unicode 搜索、过期、历史定位、建议加载、备份恢复及重开预览身份提升。适配器补采、历史证据和备份另外由核心 / 回归验证保护。

写入仍整库读取并按全局 revision 原子提交，这是保留修订 / 证据安全的本轮取舍；没有宣称写入性能已优化。超大数据的导入、容量上限、真实扩展启动与布局尚未压力验收。下一轮优先优化源头投影、搜索续扫和写入范围，详见 `NEXT_V0.4_PROMPT.zh-CN.md`。
