# V1.1.0 中文安装与操作说明

当前版本 **1.1.0**。默认完整记录读取器 **chatgpt-data-v1**，旧 DOM 兼容读取器 chatgpt-dom-v7。自动识别问答、较早消息、分支与时间，并提供常显的全文、树状图、蛇形图和时间线。更新步骤与实测范围见 [V1.1交付说明](DELIVERY_V1.1.zh-CN.md)。

术语统一为 **项目 → Conversation → 对话／Q/A**。本版修复混合标记漏回答及正文边界问题，中间直接展示完整 Q/A；每条 Conversation 有自己的目录、折叠箭头、树状图和蛇形图。

## 安装和升级

首次使用：Chrome 打开 `chrome://extensions`，启用“开发者模式”，选择“加载未打包的扩展程序”（有些版本称“加载已解压的扩展程序”），加载：

```text
D:\mytools\GPT-SaaS\apps\navigator-extension\dist\ai-conversation-visual-navigator
```

第一层须有 `manifest.json`。ZIP 是普通压缩包，须解压后选择目录，不是 CRX。源码根目录也能加载。目标 Manifest 最低 Chrome 版本为 116；当前实际 Chrome / Edge 安装与权限行为尚未验收，Edge 可在 `edge://extensions` 选择同一目录进行核对。

已有插件：先备份，关闭旧插件页，在管理页刷新**原有条目**，保留原 ID、原浏览器配置和原加载目录。标准目录和源码均已更新。不要卸载重装或另换 ZIP 解压目录。详见 `UPGRADE_V0.4.zh-CN.md`。

## 新工作台怎么用

1. 左侧选择或管理本地项目。中部下方“同项目的 conversation”选择一条；上方“切换 conversation ↓”可直接跳到列表。
2. 中间默认展开第一轮问题与完整回答。点小箭头收起／展开，用“对话目录”跳到 Q2/A2 等位置；“展开全部正文”按需取得后续完整消息。
3. 切换“树状图”或“蛇形图”，点击 Q／A 节点直接定位完整正文。加减按钮缩放图形；图形只表示阅读归属和保存路径顺序。
4. 正文未确认说话人时，仍可直接阅读；“标为问题／标为回答”只建立本地阅读标注，可用“未确认”撤回，保留来源角色未知。
5. “展开详细原文”核对来源和历史版本。“整理与导出”默认折叠，展开后可搜索、导出文档或创建资料包；按 `/` 自动展开并聚焦搜索。
6. 可靠 Q/A 的“继续阅读”恢复该项目最后一轮；未知正文的手动阅读标注暂不作为权威 Q/A 阅读偏好。
7. DOCX 可供 Word／WPS 打开；PDF 通过打印版另存。真实下载、办公软件视觉效果及当前 GPT 页面仍需按手动清单验收。JSON 备份用于完整恢复。

旧片段、主题和分支功能保留于“高级片段导航”；无需先整理片段才能看回答。

## 主动采集真实 ChatGPT

1. 打开真实 ChatGPT Conversation，确认已登录且该条可访问，无需为完整读取预先滚动加载。
2. 在该页点击工具栏插件图标，取得当前页临时授权。侧栏不可用时，代码提供带来源标签页的完整项目页入口。
3. 点击“完整读取”，取得该条全部返回消息记录、来源角色、时间和分支。

   同一标签切换到另一条 ChatGPT 对话后，可直接再次采集。已经打开的工作台优先使用最近通过图标选择的来源。采集过程中切换页面会停止本次操作，错误窗口可以直接重试当前对话。
4. 核对预览中的实际消息 / 角色数、可靠源 ID、生成状态、附件仅引用、范围、正文缺失和警告；展开消息正文分批检查。
5. 选择已有本地项目，或创建新项目。来源原生项目与本地项目分开记录；未知时可手动填来源项目名称，不会推断 ID。
6. 保存后选择 Conversation，在中间逐轮阅读问题与回答。未采到的旧消息保留，正文变化新增版本。

完整记录读取不依赖已加载 DOM，其他分支也会保存；生成中的消息注明快照，附件文件本体保留引用。完整接口失败时本次明确失败，错误窗口可直接重试。只有主动在“更多整理选项”改为旧页面正文采集时，数量才仅代表已加载部分。

失败时会区分页面不支持、尚未加载、结构无法识别、来源标签关闭和缺少授权。关闭来源页后重新打开；授权不足时在目标 ChatGPT 页面重新点插件图标。结构失败可使用官方导出 JSON，不能通过猜测正文继续保存。

## 诊断信息

采集成功预览或失败提示有“详细诊断”和“复制诊断信息”。默认仅含适配器版本、页面类型、计数、能力和已知错误类别，不含正文、账号、完整地址、标题、项目名或消息 ID。

如果界面提供附加来源信息，会先列出字段和可展开的实际内容；默认不勾选。你主动勾选后复制才包含这些信息。复制失败时可展开诊断后手动选择复制。当前预览仅提供来源地址和标题可选附加，不默认提供正文。

## 项目、地图与完整 Q/A

左侧创建 / 重命名本地项目，多条对话可放入同一项目；阅读器可移动整条对话及人工整理到其他项目。“完整项目页 ↗”打开地图、搜索与阅读器。

中间的 Q/A、目录树和蛇形图是主要阅读入口。以下片段地图及批次控制位于“高级片段导航”或辅助原文栏。

高级片段地图为 Snake 顺序浏览：节点是实际 Segment，显示标题、对话、轮次数、主题色和文字状态；灰色是未分类。时间未知按对话内顺序，连线只代表浏览顺序。筛选对话、路径、主题或整理状态不会删数据；勾选其他路径可查看已保存分支。

点击节点展开真实有序成员。完整路径 Q/A 按用户问题形成轮次，包括无回答、多助手及工具 / 辅助消息。索引每批 25 轮，支持前后批、上一轮 / 下一轮和成员序号跳转。长回答与工具折叠后首次展开才排版，正文完整保留。

导入正文使用保守 Markdown 排版：标题、段落、平面列表、引用、围栏代码、行内代码、pipe 表格、强调和普通 HTTP(S) 链接。DOM 只有实际取得并覆盖正文的结构才按结构排版；取得不了时显示普通文本。旧数据未猜测新格式。

“复制整条正文”和“复制代码”复制完整保存内容；“查看原始正文”始终显示未经排版的完整原文。代码和表格可在自身区域横向滚动。外部图片显示未自动加载，占位入口需你主动打开；来源 HTML 不执行；公式保留表达式，暂不本地公式渲染。复杂嵌套 Markdown、脚注和语法着色尚未完整支持。

“所在完整对话 / 本地原文”按批次读取所有已存消息，支持前后批并定位具体消息；“来源、身份与版本”提供源标识、时间精度、匹配依据和历史版本。其余历史版本经按钮按消息加载。整理证据指定旧版本时，明确标注并展开**确切旧正文**，顶部当前正文不会冒充历史版本。“打开保存的来源”只打开实际保存的地址，缺失时禁用。

## 整理建议与人工修改

“整理当前对话”选择阅读路径和起止轮次 → 生成本地规则建议 → 查看前后分组及真实成员 / 原文证据 → 修改标题、主题、拆合或移动相邻边界 → 保存预览 → 人工确认采用 → 地图更新。

规则结果明确标记，按连续轮次和关键词给出初步建议，不能保证语义质量；旧人工标题、主题和边界默认保护，冲突要主动复核。范围端点落在既有段内部时，预览会说明扩大到完整边界。

也可导出带稳定引用的整理包、提示词和返回格式，由你自行给外部模型，再导入完整 JSON。分批时返回全部批次；上下文不重复成为成员。导入校验 Q/A、消息、版本、路径和源签名。缺失、过期或跨分支引用不会覆盖地图。当前没有自动模型调用、API Key 或自动上传。

建议和已确认地图分别保存。取消 / 拒绝保持地图；“撤销最近修改”可撤销整次整理。源更新会让旧建议过期，已确认人工段保留并标记复核。历史建议继续可读，尚无归档功能。

阅读器中的重命名、主题、合并下一相邻段和 Q/A 边界拆分均保留完整原文及历史整理证据，不代表重新分析。管理主题的重命名 / 合并先预览影响范围，同项目相同主题色一致。

## 搜索、导入与备份

项目搜索覆盖对话标题、问题及回答正文；点击结果定位真实 Q/A、片段和原文消息。高亮直接映射保存原文，支持中文、全角、组合字符和长正文；超过一页继续读取，不截断其他结果。当前每页为准确总数重新扫描本项目，超大项目仍可能耗时。

“导入 JSON / 备份”支持 ChatGPT `conversations.json`、通用 JSON 和项目备份。先预览，再选项目保存。节点图先保留，再恢复可靠 `current_node` 路径；无法确认当前路径时由你选路径或保留未知。文件名含 demo / example / 示例 / 演示时标明示例。

“导出备份”包含项目完整原文、版本、快照、来源图、路径、Q/A、Segment 成员、主题、建议、整理包及人工修订。恢复为独立新项目便于核对，恢复会重建本地 ID；历史地图和证据保留，待确认旧建议 / 整理包需重新生成。V0.1 / V0.2 备份兼容。删除本地项目需要输入项目名，请先备份。
