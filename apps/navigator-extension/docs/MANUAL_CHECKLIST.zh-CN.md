# V1 手动体验清单

以下是需要在真实安装环境核对的清单，不表示本轮已执行这些真实环境验收。先备份已有资料；用原扩展条目、原目录和原浏览器配置升级。

## 本轮新增功能

1. 旧资料升级后检查原Q/A和版本；记忆中应有升级前恢复点。手动恢复为新项目，原项目仍在。整个资料库导出后导入应保留所有来源、标签、关联和方案。
2. 在同一个GPT标签切到另一Conversation，采集提示来源变化时点击重新绑定，核对当前标题再采集；预览后又切换应拒绝。
3. 资料包设置章节与正文顺序，保存、关闭后从页头资料包重开；原GPT更新后，已存方案仍读旧版正文。另存不覆盖原方案。
4. 关联两个Conversation的具体回答，核对来源和版本跳转；归档后可恢复。整理建议也能从记忆归档／恢复。
5. 生成独立打印页，关闭后重开；用真实Chrome另存PDF检查分页与尾部，用Word/WPS检查DOCX。

## 优先验收本轮 Q/A 功能

1. 刷新原扩展条目后确认版本 1.0.0，再刷新 GPT 来源页并重新采集。检查预览同时包含实际问题和完整回答，包含回答开头、代码前后文字、表格及最后一句。
2. 选择同项目 Conversation，中间默认第一轮 Q/A；点目录 Q2，再点其小箭头收起／展开。回答仍完整，待回答问题没有别轮答案。
3. 树状图和蛇形图点击某个 A 节点，应只标记目标消息，并把它滚到可见区域；缩放不改变正文字号。超过60轮点“继续显示目录图”检查末轮。
4. 左侧只管理项目；四个统计框不占首页；中部下方可切换 Conversation，上方切换按钮可抵达列表。窄侧栏没有整页横向溢出。
5. 未确认正文可直接阅读；手动标为 Q/A 后显示“你标注”。用“未确认”撤回，备份恢复仍保留原始角色与正文版本。
6. 按 `/` 自动展开搜索工具；点击搜索结果定位同一轮与确切消息。默认右栏收起，主 Q/A 阅读不依赖右栏。

## 先核对排版与文件

1. 版本 0.7.0；侧栏采集后展开诊断，滚到正文底部。三个底部按钮应完整可见，提示不覆盖按钮。空新项目名点击保存，应在弹窗顶部看到错误，正文保留。
2. 保存一条含代码、表格、长回答的真实对话。“导出文档”预览后生成 DOCX，确认下载完成，用 Word/WPS 核对中文、可编辑代码/表格及最后一句。
3. 选择 PDF，打开打印版后 Ctrl+P → 另存为 PDF；核对分页、尾部、来源附录。打印完成后再关插件页面；另存 HTML 可保留离线打印来源。
4. 两三条对话归入同项目，“创建资料包”添加章节，批量分配对话，取消一段，调整章节顺序，预览及导出均应一致。制作方案当前不持久保存。
5. 取消用户问题仅排除平台可靠用户角色；零问答、未确认角色的原文仍保留。取消来源附录后文件的隐藏来源字段也不应残留。JSON 备份继续单独保留。

## 继续核对保留的高级片段导航

1. 同项目保存至少两条对话，切换对话总览、顺序地图、主题视图、问答列表，核对计数与原文来自同一份数据。
2. 筛选对话标题、主题和整理状态；点面包屑回到项目。多主题片段可同时出现，主题颜色在四种视图中一致。
3. 阅读某一轮后关闭重开，再点“继续阅读”；切换另一项目后原阅读位置仍保留。拆分 / 合并片段再恢复，定位同一 QA 而不是失效旧节点。
4. 开启专注阅读，展开来源、编辑操作和目录，点击“查看本段问答列表”应返回可见地图。检查 `/`、`Escape` 和 `Alt + ← / →`。
5. 收起桌面导航；缩窄窗口并打开 / 关闭抽屉；侧栏展开对话列表后选择一条应自动收起。按钮可点，整个页面没有横向溢出。
6. 在复核筛选下执行项目全文搜索，点击命中应切换到真实来源并清理旧筛选。搜索正文先精确高亮，表格可从排版入口展开。

## 继续核对原闭环与真实权限

1. **升级旧资料**：刷新原条目，重新打开已有项目；人工标题、主题、分段边界、历史证据和撤销仍在。导入 V0.1 / V0.2 备份到新项目核对。
2. **普通与项目内采集**：打开两类真实 ChatGPT 页面，在来源页点插件图标再采集；预览数字与本次实际展示消息一致，不宣称完整历史。未知原生项目、分支和时间保持未知。
3. **范围与失败**：空页 / 加载中、其他网站、关闭来源标签、未取得当前页授权分别检查明确原因。结构识别失败应保留已有数据并给导入入口建议。
4. **诊断隐私**：默认复制检查没有正文、账号、URL、标题和项目名；附加先展示具体内容、默认未勾选；勾选后才复制所列内容。
5. **生成与重复保存**：保存生成中回答，稍后更新；消息身份保持，正文版本增加，旧正文可读。相同文本但不同源 ID 的消息不能错误合并。
6. **滚动补采**：加载更早历史或中间遗漏问题后更新；旧消息不因离开 DOM 被删除，当前回答归属更新；历史整理证据、复核和备份仍完整。
7. **完整回答**：展开长回答，核对尾部；复制整条正文与代码并粘贴比较；关闭折叠后重新展开仍完整。
8. **Markdown 和 DOM 格式**：导入含标题、列表、引用、代码和表格的文件；代码 / 表格横向滚动，原文入口保留完整格式字符。DOM 取得不了结构时应明确显示普通文本。
9. **安全与窄侧栏**：来源 HTML 只显示文本，图片不自动请求，公式保留表达式；窄侧栏没有整页横向溢出，代码和表格自身可横滚。
10. **完整轮次**：未回答用户问题形成 Q/A；多助手及工具属于可靠路径中的真实轮次，工具和附件独立折叠。上一轮、下一轮、跳转及索引下一批均可读。
11. **历史证据定位**：确认整理后更新正文，打开旧整理证据；确切旧版本明确展开，不能只显示最新回答；其余版本经按钮加载。
12. **项目与全文搜索**：两条对话存入同项目，搜索问题和回答。核对中文、全角、组合字符及长回答末尾命中；超过 35 个结果继续读取，点结果同步 Q/A、片段及原文。
13. **建议闭环**：生成规则建议，编辑标题、主题和边界；预览未采用时地图保持；确认后新片段展开真实连续成员。导出整理包及提示词，再导入外部 JSON 核对引用。
14. **拒绝、过期与撤销**：拒绝不改地图；确认后整次撤销；人工段默认保护；源更新后旧建议不能静默采用，需要复核状态不被拆合清除。
15. **地图与主题**：片段重命名、设置主题、相邻合并、边界拆分；地图与 Reader 双向选择；主题重命名 / 合并先显示影响范围，同项目颜色一致。
16. **持久化与备份**：关闭重开 / 刷新后原文和人工修改仍在；导出项目备份到新项目重导入，核对版本链、证据和成员。恢复后的待确认建议应过期并要求重新生成。
17. **真实权限与浏览器**：分别确认 Chrome / Edge 的工具栏、Side Panel、服务工作线程、activeTab / scripting、来源切换、系统剪贴板与下载。当前桥接检查不能替代这项。

500 / 2,000 轮性能样例在 `validation/`，属于明确标记的隔离验证数据，未打包、未写入用户扩展项目。测量范围与局限见 `PERFORMANCE_V0.3.zh-CN.md`。
