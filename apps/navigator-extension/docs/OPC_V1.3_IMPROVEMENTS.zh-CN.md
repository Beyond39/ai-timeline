# OPC Timeline 1.3 增量改进与验收

本次继续修改现有插件。原有项目、消息、版本、快照和备份保留；浏览器权限与同源主动读取方式未扩大。没有引入 AI API 或远程脚本。

## 本轮审查结论

1. 1.2 的多线对照只按当前页计算时间范围，翻页会改变坐标；关联导航以单卡过滤替代翻页，缺少上下文。
2. 标注表单在视图重建时丢弃未保存内容，没有校验另一窗口是否修改过同一标注或关系。
3. 画布提交整份坐标，可能覆盖其他窗口移动的节点；每次 pointermove 都重建全部 SVG 连线。
4. 详情仍读取工具、分析和状态消息的正文；回答部分缺失时可能被标为完整，附件只有引用时没有正常的静态阅读内容。
5. 搜索翻页会重复扫描全文；返回所有成员及关系使分页响应随资料库增长。

## 第一阶段：导入投影、状态与数据一致性

修改：`domain/qa-content.js`、`domain/opc.js`、`storage/database.js`、`storage/opc.js`、`ui/dom.js`。

- 缺少正文、仅有附件引用的回答明确标为“内容缺失”，只包含工具和分析的已结束记录不冒充完整回答；分析/工具尚在生成且尚无正文时仍可显示生成中。
- 附件以文件名及“正文未导入”转成静态阅读内容，原始记录保留。空问题不再误标成“包含附件”。
- 结构化代码块根据正文中的反引号选择更长围栏，保留包含 Markdown 围栏的代码示例。
- 日期精度的来源只显示日期，避免展示推算出来的小时和分钟；未知时间继续显示未知。
- IndexedDB V6 增加卡片、元数据、成员及关系端点索引。详情只取问题、可见回答、当前卡片的标注和关系，不加载工具正文。
- 新版投影标记使旧卡片首次阅读时重新分类，保留 ID、元数据、关系和归属。备份拒绝重复逻辑卡片或重复元数据。
- 标注、关系及时间线增加 revision 检查，旧版没有 revision 的记录按 0 兼容。

验证：新增 `validate-opc-improvements.mjs` 的状态、附件、围栏、日期及并发用例通过；原有导入、核心、渲染器、完整对话与备份回归通过。浏览器确认详情只读 3 条所需消息；V4/V5→V6 的真实 IndexedDB 升级通过。

遗留与下一步：历史采集如果从未保存频道信息，不能凭空恢复，重新导入当前对话可补齐。真实登录页面采集及已安装 MV3 环境仍需联调；其余时间线和画布改进已继续完成。

## 第二阶段：长时间线、多线对照与导航

修改：`domain/opc.js`、`storage/opc.js`、`ui/opc.js`。

- 后端计算整个筛选范围的共享时间范围；前后页保持相同横坐标尺度，未知时间不进入坐标。
- 通过稳定 ID 定位目标所在页并保留相邻卡片，不再把列表缩成单张卡片。
- 分页成员/关系返回范围限定于显示卡片；卡片正文仍按需读取。
- 同一资料版本的全文搜索命中缓存最多保存 8 组，翻页无需再次扫描聊天正文；任何数据库写入改变 revision 后缓存失效。
- 批量成员操作通过 Map/Set 查找，减少重复扫描。

验证：10,000 张摘要的排序分页、150 张摘要的跨页坐标/导航用例通过。浏览器实际导入 180 轮长对话，60 张摘要分页、最后答案完整尾部、目标页定位和搜索缓存通过。

遗留与下一步：全文搜索的首次查询仍按项目扫描消息；极大资料库可进一步采用倒排索引。接下来的关系和画布补强已完成。

## 第三阶段：标注草稿、关系与画布

修改：`ui/opc-drafts.js`、`ui/opc.js`、`ui/opc.css`、`domain/opc.js`、`domain/canvas-layout.js`。

- 未保存标题、标签、备注在本地保留草稿。刷新、切换视图、重新打开页面后可恢复；不同窗口使用各自草稿键。
- 保存检查读取时的版本。冲突时保留草稿并展示已保存版本，核对后可基于最新版本继续编辑；不会默默覆盖另一窗口内容。
- 关系编辑和删除也检查版本。关联区显示目标问题及来源，便于识别节点。
- 画布可按需展开最多 40 个跨页关联节点，使目标与关系在同一画布出现；可收起额外节点。
- 拖动只提交移动节点的坐标，平移/缩放才提交视口。校验移动前的位置：不同节点可独立保存，同节点冲突会拒绝覆盖。
- 连线 DOM 建立后复用，按动画帧仅更新移动节点相关的边，避免每个鼠标事件重建全部连线。
- 改善反向和垂直连接端点、滚轮缩放坐标及指针取消后的事件清理。

验证：Node 验证草稿恢复、并发修改、独立节点合并、同节点冲突无部分写入及连线几何；浏览器验证草稿保留、冲突拒绝、跨页节点与真实关系显示、页面重启恢复。

遗留与下一步：画布继续限制主要页面 60 个节点、额外关联最多 40 个。未来可增加空间虚拟化以及更多节点展开方式；当前阶段继续完成回归与打包。

## 使用与复验

升级原来的解压加载目录 `dist/ai-conversation-visual-navigator`，关闭旧插件页面，在 Chrome/Edge 扩展管理页重新加载原条目。保留同一扩展身份，避免另装一份而看不到原数据。

```powershell
node scripts/validate-all.mjs
node --experimental-vm-modules scripts/build.mjs
node scripts/verify-package.mjs
node scripts/serve-validation.mjs 8939
```

每次完整浏览器验收使用新隔离名，例如 `http://127.0.0.1:8939/workspace.html?validationDb=v04-opc-v13-check1`。点击“运行 OPC 浏览器验收”，刷新后点击“验证 OPC 重启持久化”，通过“保存 OPC 验收报告”导出结果。

V5 升级单独使用 `http://127.0.0.1:8939/workspace.html?validationDb=v04-opc-migration-v5-check1&legacyOPC5=1`，V4 使用 `http://127.0.0.1:8939/workspace.html?validationDb=v04-opc-migration-v4-check1&legacyOPC=1`，进入后点击“验证 OPC 旧库升级”。这些合成资料始终使用独立数据库。

下一步优先在真实 ChatGPT 页面验证完整读取、流式同步、重新生成分支，以及安装后的浏览器关闭/重新打开；随后评估首次全文搜索和大型资料库导入的性能。当前基础功能保持本地处理，不上传聊天正文，不新增浏览器权限。
